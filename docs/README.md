# PantryPlus

PantryPlus is a smart pantry management app that helps users track the food items in their pantry, monitor expiration dates, and reduce food waste. Through a simulated scanning feature, users can quickly add items to their pantry as if scanning them in real time.

## Features (Planned)
- Track pantry items: name, quantity, expiration date, and category
- Expiration warnings to reduce food waste
- Simulated barcode/item scanning to add items quickly
- Dashboard view of current pantry contents
